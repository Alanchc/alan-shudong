## 二、涉及的知识点

### 1. 命令行与环境

- **PATH 环境变量**：装完新工具要重开终端；为什么直接敲 `npm` 会命中 `npm.ps1` 被拦。
- **用户级安装 vs 管理员安装**：无管理员权限时如何绕开 UAC（官方 ZIP / PortableGit）。
- **PowerShell 执行策略**：`Restricted` 会阻止脚本执行，需要 `RemoteSigned` 或改用 `.cmd`。

### 2. Git 与 GitHub

- `init / add / commit / push` 四个基本动作。
- `.gitignore` 的意义：`.env.local`、`.vercel` 这类含密钥或本机配置的文件不能进仓库。
- **SSH 公钥认证**：私钥留本地，公钥交给 GitHub；私钥泄露等于账号被接管。
- HTTPS 证书校验失败（`CRYPT_E_NO_REVOCATION_CHECK`）时的排查与替代方案。

### 3. 前端

- **React**：组件、`useState` 状态、`useEffect` 副作用、受控输入、`ref`。
- **Next.js**：目录即路由（`app/page.tsx` → `/`）、动态路由（`app/s/[slug]`）、`"use client"` 的含义。
- **响应式**：媒体查询（`@media (max-width: 900px)`）、`dvh` 单位、iPhone 刘海安全区（`env(safe-area-inset-*)`）。
- **CSS 变量**做主题：通过 `data-theme` 属性切换深浅色。

### 4. 数据与安全（本项目最核心）

- **关系表设计**：主键、外键、`text[]` 数组字段、`timestamptz` 时区字段。
- **RLS（行级安全）**：`using`（读/改哪些行）与 `with check`（写入时校验）的区别；`auth.uid()` 的用法。
- **权限必须放在数据库**：前端过滤只是体验，RLS 才是真正的防线；前端代码谁都能改。
- **Storage**：bucket、对象路径约定（`uid/随机名.ext`）、公开桶与签名 URL 的取舍。

### 5. 鉴权

- 邮箱密码注册与登录流程。
- session 的获取与监听：`getSession` / `onAuthStateChange`。
- 未登录状态的降级处理（提示 + 跳转登录）。

### 6. 部署与网络

- 构建（`next build`）与产物、环境变量在云端如何配置。
- 自定义域名：A 记录、CNAME、308 重定向、HTTPS 证书自动签发。
- DNS 查询与证书 CN 不匹配（`ERR_CERT_COMMON_NAME_INVALID`）的含义。
- 国内访问境外服务的现实问题：`vercel.app` 被 DNS 污染、Vercel 节点延迟不稳定。

## 三、需要自学的内容（按优先级）

### 必学

| 主题 | 判断标准 |
|---|---|
| Git 四个命令 | 能自己完成一次「改代码 → 提交 → 推送 → 看到自动部署」 |
| React 组件与状态 | 能看懂 `Editor.tsx` 里标题输入为什么实时更新预览 |
| CSS 布局（flex / grid / 媒体查询） | 能自己调手机端间距而不破坏桌面端 |
| Supabase 表 + RLS | 能说清「为什么新账号看不到我的日记」 |

### 建议学

| 主题 | 判断标准 |
|---|---|
| SQL 基础 | 能在 SQL Editor 查出「我这个月写了多少篇」 |
| Next.js 路由约定 | 能自己新增一个 `/about` 页面 |
| DNS 与域名 | 换域名时能自己加解析记录 |

### 可以先不学

TypeScript 类型体操、Vercel CLI 细节、SSH 协议原理、Postgres 索引优化——目前由开发助手处理，遇到性能或安全问题再补。

### 推荐学习顺序

```
Git 四命令 → React 状态 → CSS 布局 → Supabase 表与 RLS → SQL 查询 → Next.js 路由
```

每项 2–3 小时即可，不必学完再动手。最有效的方式是「想改一个小地方就说出来，改完对照 diff 看」。

## 五、上线链路速查

```
本地改代码
   ↓ git push
GitHub（Alanchc/alan-shudong）
   ↓ Vercel Git 集成（自动触发）
Vercel 构建 → 部署 → 别名
   ↓ DNS（DNSPod：A 76.76.21.21 / CNAME cname.vercel-dns.com）
https://www.alan-space.top
   ↓ 读写
Supabase（Postgres + Auth + Storage）
```

注意事项：

- Supabase 免费项目连续 7 天无请求会暂停，需在后台 Restore。
- `.env.local` 只在本地生效，线上环境变量配在 Vercel 项目设置里。
- 数据库权限改动后，务必用「无痕窗口注册新账号」验证一次数据隔离。
